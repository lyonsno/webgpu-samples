Packed dot products

Store four signed 8-bit values in each 32-bit word. WebGPU’s dot4I8Packed takes two of these words, multiplies corresponding values, and adds the four products.

How the GPU handles four pixel pairs at once

The GPU computes the same squared error using Σ(p−t)² = Σp² + Σt² − 2Σpt. The two sums of squares can be prepared in advance; dot4I8Packed supplies the dot-product term for four matching pixel pairs at a time. Subtracting 128 from both patches fits their values into signed bytes without changing their differences.

Squared error = patch’s sum of squares + cutout’s sum of squares − twice their dot product.

Four pixel pairs make one packed dot. A full patch has 1,024 pixels, so it needs 256 packed dots for one score. Repeating that across 14,641 positions produces the map; the smallest score wins.
