Packed integer dot products

A dot product multiplies matching values in two lists, then adds the results. Packed integer dot products do this on four pairs of 8-bit values, with each group of four stored in one 32-bit word.

Why a vision model uses this

A vision model builds new features by combining responses to patterns, such as edges, with learned weights. It repeats these weighted sums across an image. Quantized models approximate inputs and weights with small integers to reduce memory and data movement. Explore one four-value group from a sum below.

Inside a byte: signed bits

Flip a bit to change the selected value and its product. Each set bit adds the amount below it; the high bit contributes −128. This is the two's-complement encoding of a signed 8-bit integer.

From four values to a neural-network layer

A 64-input sum takes 16 groups like this. A real layer accumulates the groups, includes a bias, and applies quantization scales and any zero-point corrections. This feature-combining operation is called channel mixing, or a 1×1 convolution.

Four 8-bit values occupy one 32-bit word instead of four 32-bit values. On GPUs with native packed-dot support, the operation also avoids separate unpacking and multiplication in shader code. Speed depends on the hardware and workload; this small example is not a benchmark.
