Find an image patch with packed dot products

dot4I8Packed multiplies four pairs of signed bytes and adds their products. Here, many packed dots search for a 32×32 grayscale template: each candidate gets a sum of squared pixel differences. Lower error means a closer match.

We search 14,641 overlapping windows on a four-pixel grid, not every pixel offset. Four adjacent pixels occupy one word. Subtracting 128 maps grayscale 0–255 to signed bytes −128–127 without changing pixel differences. Hex writes the low byte (first pixel) at the right.

Why use packed dots for squared differences?

E = P·P + T·T − 2P·T. The template term is computed once; each group of four pixels needs two packed dots. The GPU performs about 7.5 million packed dots per search and renders the error buffer directly. Toggle the natural scalar subtraction-and-square path to compare GPU compute time on your device. This is brightness-sensitive patch matching, not rotation/scale-invariant object recognition.
