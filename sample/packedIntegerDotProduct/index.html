Find this cutout in the picture

Where did this small piece come from? The GPU compares its pixels with 14,641 locations in the picture and finds the closest match. This is template matching, a way to locate a known image inside a larger one.

Searching the picture…

These cutouts come from the picture, so an exact match exists. The search receives the cutout's pixels, not its original position. It compares overlapping 32×32 windows at four-pixel steps.

How packed dot products do the search

A match score adds up squared pixel differences: identical patches score zero. dot4I8Packed multiplies four pairs of signed bytes and adds the products, letting us compare four pixels together. Millions of these small operations produce the landscape above. 


      

        Four adjacent grayscale pixels occupy one word. Subtracting 128 maps
        0–255 to signed bytes −128–127 without changing their differences. The
        first pixel is the low byte, shown at the right in hexadecimal.
      

      

        E = P·P + T·T − 2P·T. The image's window energies are
        prepared once; each new cutout uses about 3.75 million packed
        cross-dots. The GPU supplies every error to the landscape; JavaScript
        selects the minimum from the downloaded scores. Uncheck the box to
        compare scalar subtraction-and-square compute time. This matches pixel
        intensities; it does not handle rotated or resized objects.
