Find this cutout in the picture

Where did this small piece come from? The GPU compares its pixels with 14,641 locations in the picture and finds the closest match. This is template matching, a way to locate a known image inside a larger one. Packed dot products let the GPU compare four pixel pairs at a time; the views below show the match errors they produce.

Each target is cut from this picture, so the best match has the same pixels. The search discovers where they are.

Selected comparison location

Changing this location moves the dashed white markers; the search target stays the same until you press the button. The search receives the target's pixels, not its original position. It compares overlapping 32×32 windows at four-pixel steps.

How the selected comparison gets its score

A match error adds squared pixel differences; identical patches score zero. The useful rewrite is (p − t)² = p² + t² − 2pt: prepare the sums of squares once, then compute the dot product for each possible match.

Match error = picture’s squared values + cutout’s squared values − 2 × their dot product

The blue outlines mark four adjacent pixels in each patch. Each tile below shows its grayscale value, with its signed byte underneath: subtracting 128 from both sides fits −128…127 and preserves their difference. Four bytes share one u32 word.
