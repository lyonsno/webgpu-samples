Packed integer dot products

A dot product multiplies matching values in two lists, then adds the results. The packed version works directly on four pairs of 8-bit integers, helping quantized neural networks compute with compact data.

Why a vision model uses this

At each image location, a channel-mixing layer combines input features with learned weights to produce a new feature. Quantization approximates these numbers with small integers. Explore one group of four from that weighted sum below.

From four values to a neural-network layer

A 64-input sum takes 16 groups like this. A real layer accumulates the groups, includes a bias, and applies quantization scales and any zero-point corrections. Channel mixing is also called a 1×1 convolution.

Four 8-bit values occupy one 32-bit word instead of four 32-bit values. On GPUs with native packed-dot support, the operation also avoids separate unpacking and multiplication in shader code. Speed depends on the hardware and workload; this small example is not a benchmark.
